## 3. Gaps

### 3.1 New findings this pass

**N1 — the status baseline drifts by construction.** *(defect)*

Both declared sources of truth were refreshed to `a81600e` / 86 commits. Three
commits have landed since, in the same session, so both now declare a baseline
**3 commits behind HEAD**. This is not carelessness; a manually written baseline
is stale the moment the next commit exists. The refresh fixed the symptom once
and cannot keep it fixed.

The durable remedy is a control asserting the declared baseline equals `HEAD`,
or generating the header from git at commit time. Neither exists. Until one
does, every future commit re-creates this gap.

**N2 — the real-process layer of termination evidence is not gate-enforced.**
*(structural)*

Seven controls in `tests/workload/test_termination_evidence.py` spawn real
processes: a gcc-compiled NULL dereference, a real `taskkill`, a real
`subprocess.run` timeout. `tests/workload` is **not a gate**, so none of them run
in any gate. Three unit controls assert that file exists and still names the
required cases, which catches deletion or renaming — but not a control that is
edited into vacuity while keeping its name.

**N3 — the boundary deviation's wording is stale.** *(defect, minor)*

`audit_boundaries.py` records `DEVIATION 2.9 GATE B: no guard against a second
live controller`, with a note that `test_transport_path_keeps_one_controller` is
"a tracked expectedFailure until the migration lands" and "flips to a hard check
at M1.3". M1.3 has landed, and `test_runtime_isolation.py:93-99` documents that
the decorator was **deliberately removed** because the correct end state is that
`CaptureSession` stays unused on the transport path with its hazard documented.

The deviation itself is **correct and intentional** — `CaptureSession` can still
hold several live controllers, and that is now a documented residual property,
not a pending item. Only the note is wrong, and a maintainer reading it could
reasonably think the work is outstanding.

**N4 — "declared" is not "reproducible".** *(structural)*

G4 converted the corpus from an implicit assumption into a declared external
prerequisite, and that is exactly what was ruled. But a fresh clone still cannot
run `integration`, `cold_warm_equivalence` or the workload suite: 0 tracked
`.rdc`. What changed is that the gap is now **visible and auditable** rather than
silent. It is not closed, and the Contract's §7 deliberately leaves acquisition
and a corpus manifest out of scope.

   capability ever becomes available.
6. **Attribution, then release blocking** — in that order, both blocked.
